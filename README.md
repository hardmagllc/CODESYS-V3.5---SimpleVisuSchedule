# CODESYS V3.5 - SimpleVisuSchedule library

A library for the CODESYS V3.5 PLC programming environment that allows implementing schedule-based control.

**Supported CODESYS version:** V3.5 SP17 Patch 3 or later.

This is a fork of the [original SimpleVisuSchedule library](https://github.com/CodesysOneLove/CODESYS-V3.5---SimpleVisuSchedule) by CodesysOneLove.  
Modifications and multi-language support by Artem Melnik / HARDMAG LLC.
